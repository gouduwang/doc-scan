# 证件扫描工具

**100% 本地处理 · 零上传 · 可离线使用**

纯前端证件扫描工具，支持身份证、银行卡、驾驶证、行驶证、护照、户口本、结婚证、毕业证、房产证、营业执照等 20 种证件类型，透视矫正、扫描增强、防盗用水印、A4 排版、PNG/PDF 导出。

## 特性

- 🔒 **隐私保护**：所有图像处理在浏览器本地完成，图片不会上传到任何服务器
- 📱 **PWA 支持**：可添加到手机主屏幕，离线使用
- 📐 **透视矫正**：手机斜拍照片自动拉正（单应变换）
- ✨ **扫描增强**：直方图白平衡拉伸，灰度、黑白复印滤镜
- 💧 **防盗用水印**：平铺斜排水印文字（如"仅供办理XX业务使用"）
- ✍️ **用途声明**：按办事惯例将"此件仅用于办理XX，他用无效"+日期压写在证件图面上（防裁剪去除），内置常用语快选
- 📑 **多页文档**：合同文件/普通文档支持"＋添加一页"动态增删（最多 20 页），A4 自动分页
- 📄 **A4 排版**：300 DPI 实际尺寸，正反面自动排布，超出一页自动分页
- 💾 **多格式导出**：多页 PNG、多页 PDF（手写生成器，无外部依赖）、直接打印
- 🌐 **在线模式开关**：默认纯本地；可开启"在线增强"预留通道，后续在自有服务器上部署 AI 去水印/去手写等接口即可启用（`API_BASE` 常量处替换域名，接口约定见代码注释）
- 📁 **我的文件夹**：做好的扫描件可一键存入本机浏览器（IndexedDB），下次办事直接下载 PDF/PNG，无需重拍重裁；文件不上传，清除浏览器网站数据会一并删除
- ⭐ **自定义主界面**：默认只展示 8 种常用证件，点"⚙ 自定义"可用 ★ 收藏/移出证件类型，每人定制自己的常用场景（设置存本机 localStorage）
- 🌍 **多语言**：中文/English 切换（🇨🇳/🇺🇸），词典式架构可随时扩新语言
- 🎨 **主题与字号**：默认浅色 / 护眼绿 / 深色三套主题，标准/大/特大三档字号，设置存本机
- 🔠 **识别文字（OCR）**：Tesseract.js WASM **在本机浏览器内**识别中英文文字，不上传图片；首次使用联网下载约 35MB 组件（优先取本站自托管的 `ocr/` 目录，不含任何第三方 CDN 依赖），Service Worker 缓存后可离线
- 📤 **分享**：手机上调系统分享面板（Web Share API），桌面端自动复制分享文案
- 💬 **投诉与建议**：内置反馈弹窗（类型快选+正文+选填联系方式，不强制手机号）；服务器就绪前自动降级为复制反馈内容线下发送，预留 `/v1/feedback` 接口

## 支持的证件类型（20 种）

**个人证件**：身份证、银行卡、驾驶证、行驶证、护照、港澳通行证、台湾通行证、社保卡、居住证

**证书凭证**：结婚证、毕业证书、学位证书、出生证明、不动产权证、户口本（默认户主页+本人内页，可动态加页）

**企业证照**：营业执照、组织机构代码证、税务登记证

**其他**：合同文件（3页）、普通文档

## 本地使用

直接用浏览器打开 `index.html`（即原 `证件扫描工具.html` 重命名后）即可使用。推荐使用 Chrome、Edge、Safari 最新版。

手机端建议通过 HTTP 服务访问（见下方部署说明），这样可以：
- 直接调用系统相机拍照
- 添加到主屏幕作为 PWA 应用
- 离线使用

## 部署到线上

### 方式一：Cloudflare Pages（推荐，全球可用）

1. 在 [Cloudflare Dashboard](https://dash.cloudflare.com) 创建 Pages 项目
2. 上传本目录的内容（至少 `index.html`、`manifest.json`、`sw.js` 三个文件；建议连 `ocr/` 一起上传，见下方清单）
3. 部署后自动获得 `xxx.pages.dev` 域名，支持 HTTPS

**优点**：免费、全球 CDN、自动 HTTPS、国内大部分地区可访问

### 方式二：GitHub Pages（免费，国内访问不稳定）

1. 创建 GitHub 仓库，上传本目录内容（至少 `index.html`、`manifest.json`、`sw.js`；`ocr/` 建议一并上传）
2. 在仓库 Settings → Pages 启用，选择分支
3. 访问 `https://用户名.github.io/仓库名`

**优点**：免费、简单
**缺点**：国内访问时好时坏

### 方式三：国内对象存储（需 ICP 备案，国内访问快）

**腾讯云 COS** / **阿里云 OSS** / **七牛云**：

1. 创建对象存储桶，开启"静态网站托管"
2. 上传本目录内容（至少 `index.html`、`manifest.json`、`sw.js`；`ocr/` 建议一并上传）
3. **绑定自有域名需要 ICP 备案**（个人非经营性备案约 1-2 周）
4. 配置 CDN 加速

**优点**：国内访问快、稳定
**缺点**：需要域名备案、有一定成本（但流量费用很低）

### 部署文件清单

| 文件 | 必需 | 说明 |
|---|---|---|
| `index.html` | ✅ | 全部界面与逻辑（单文件） |
| `manifest.json`、`sw.js` | ✅ | PWA 安装与离线缓存 |
| `icon-192.png`、`icon-512.png`、`apple-touch-icon.png` | 建议 | 安装到主屏幕的图标 |
| `ocr/`（约 35MB） | 建议 | Tesseract.js 自托管组件。**不传也能用**，但 OCR 首次会改走公共 CDN（多一条外部依赖） |

### 重要提示：文件重命名

部署前务必将 `证件扫描工具.html` **重命名为 `index.html`**，因为：
- `manifest.json` 和 `sw.js` 中引用的是 `index.html`
- 大部分静态托管服务默认首页是 `index.html`

## PWA 功能

用户通过 HTTPS 访问后（本地 `file://` 不支持）：

- **Chrome/Edge（桌面）**：地址栏右侧会出现"安装"图标
- **Safari（iOS）**：点击分享按钮 → "添加到主屏幕"
- **Chrome（Android）**：自动弹出安装提示，或页面底部"添加到主屏幕"链接

安装后作为独立应用运行，支持离线使用。

## 技术栈

- 纯 HTML + JavaScript（ES6+）
- Canvas 2D API：图像处理、透视变换、滤镜
- 手写 PDF 生成器（多页，每页内嵌 JPEG，符合 PDF 1.4 标准，无外部依赖）
- Service Worker：离线缓存
- PWA Manifest：应用化体验

## 隐私与安全

- ✅ 所有计算在本地浏览器完成
- ✅ 图片不会上传到任何服务器
- ✅ 无用户追踪、无统计代码
- ✅ 可断网使用（部署后访问一次即可离线）
- ✅ 开源透明，代码可审计

**验证方法**：部署后打开浏览器开发者工具（F12）→ Network 标签页，处理证件照片时可以看到没有任何网络请求（除了首次加载页面本身）。

## 法律声明

⚖️ 请仅处理**本人证件**并用于合法用途。建议在扫描件上加注水印说明用途（如"仅供办理XX业务使用，他用无效"），防止被挪作他用。

根据《中华人民共和国居民身份证法》，伪造、变造或冒用他人身份证件属违法行为。本工具仅提供扫描件生成功能，不支持也不鼓励任何形式的证件伪造。
